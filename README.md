# Flatline Fighters

Choose a custom combat bot and enter a neon free-for-all where every match is a scramble to ram, slam, grab, and throw rival machines into glowing arena pits. Survive one round after another, adapt to different stage layouts, and build a win streak before the arena finally takes you out.

Part of the [sloopygames.com](https://sloopygames.com) collection.

## Play

Open `index.html` in any modern browser. Single self-contained file -- no build step, no dependencies.

## How to Play

- Defeat three AI-controlled rival bots and be the last machine standing in each match.
- Knock enemies into pits for instant eliminations, or wear down their health with slams and pushes until they are destroyed.
- Winning a round advances you to a new arena and increases your run's total win count until you are eliminated.
- Some stages can trigger random arena events such as EMP bursts, quakes, gravity flips, and healing storms.

## Controls

- **WASD / Arrow Keys** -- move
- **N** -- slam attack
- **B** -- push attack
- **M** -- grab, then throw when already holding an enemy
- **While grabbed: N / B** -- struggle to break free
- **Touch D-pad** -- move on mobile
- **Touch SLAM button** -- slam on mobile
- **Touch GRAB button** -- grab or throw on mobile
- **Touch HAMMER button** -- push attack on mobile

## Features

- Six selectable robot archetypes with different speed, defense, and attack strengths.
- Eight neon arena themes with different pit layouts and optional stage events.
- Procedural run structure with consecutive matches and tracked win totals.
- Dynamic synth soundtrack and sound effects generated in code.
- Single-file HTML5 Canvas game.

## Tech

- HTML, CSS, vanilla JavaScript
- HTML5 Canvas
- Web Audio API for synthesized music and sound effects
